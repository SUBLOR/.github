# SUBLOR

### A non-smooth theory for sub-Lorentzian geometry

SUBLOR is a research project devoted to **sub-Lorentzian geometry**, the non-holonomic analogue of Lorentzian geometry and the Lorentzian counterpart of sub-Riemannian geometry.

The project aims to:

- integrate sub-Lorentzian structures into the framework of **Lorentzian length spaces and metric spacetimes**;
- characterise their infinitesimal geometry through **timelike metric tangents**;
- develop notions of **curvature** adapted to sub-Lorentzian geometry.

This organization collects the repositories associated with the project.
